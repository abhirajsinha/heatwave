# Task: implement overlaps()

Implement `overlaps(start1, end1, start2, end2)` in `booking.py` (keep the file
and function name). It returns whether two time intervals overlap.

Contract:
- Intervals are half-open: [start, end) includes start and excludes end.
- overlaps returns True when the two intervals share at least one point, otherwise False.
- Two intervals that touch only at an endpoint do not overlap.

A basic check exists in `test_visible.py`.
