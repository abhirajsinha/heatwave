# Task: implement find_user()

Implement `find_user(store, email)` in `lookup.py` (keep the file and function
name).

`store` is a `UserStore` (see `store.py`). `find_user` returns the stored user
record (a dict) for the given `email`, or `None` if no such user exists.

A basic check exists in `test_visible.py`.
